# ArmyVAI Wiki

Статический шаблон вики для публикации на GitHub Pages. Сайт не требует сборки, Node.js или сторонних библиотек.

## Файлы

- `index.html` — структура страниц и интерфейса.
- `styles.css` — оформление, адаптивная вёрстка и мобильное меню.
- `app.js` — навигация, поисковая функция и тексты демонстрационных статей.
- `assets/favicon.svg` — значок сайта.
- `.nojekyll` — отключает обработку Jekyll для статических файлов.

## Публикация на GitHub Pages

1. Войдите на [GitHub](https://github.com/) и создайте новый репозиторий с названием `ArmyVAI`.
2. На странице репозитория нажмите **Add file → Upload files**.
3. Загрузите содержимое этой папки в корень репозитория — `index.html` должен лежать в корне, а не во вложенной папке.
4. Нажмите **Commit changes**.
5. Откройте **Settings → Pages**.
6. В блоке **Build and deployment** выберите **Deploy from a branch**.
7. Выберите ветку `main` и папку `/(root)`, затем нажмите **Save**.
8. Подождите, пока публикация завершится. Адрес будет выглядеть так: `https://ВАШ-ЛОГИН.github.io/ArmyVAI/`.

Подробная инструкция GitHub: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Как изменить содержание

Откройте `app.js` и найдите объект `articles`. Для каждого раздела доступны `title`, `lead` и массив `sections`. У каждой секции два элемента: заголовок и текст. Замените демонстрационные тексты на материалы вашей тематики.

Чтобы переименовать разделы меню, измените кнопки `data-page` в `index.html` и объект `pageNames` в `app.js`. Для изменения цветов и оформления редактируйте CSS-переменные в начале `styles.css`.

## Важно

Сейчас это стартовый макет: тематика и реальные материалы ещё не указаны. Перед публикацией замените демонстрационные тексты и проверьте все сведения. Сайт статический — для аккаунтов пользователей, приватной панели редактирования или базы данных понадобится отдельный backend.
