РЕДАКТИРОВАНИЕ

Как настроить
ArmyVAI

Шаблон создан без сборки и внешних библиотек — его можно публиковать прямо на GitHub Pages.

1. Измените название и описание

Откройте index.html и измените заголовок, подпись и описание под тематику вашего проекта.

2. Добавьте статьи

Откройте app.js. В объекте articles можно поменять заголовки, описания, пункты и содержимое страниц. Навигационные разделы на главной уже подключены.

3. Настройте внешний вид

Цвета, отступы, карточки и мобильная версия находятся в styles.css.

4. Опубликуйте

Создайте репозиторий ArmyVAI, загрузите в корень все файлы архива, затем откройте Settings → Pages. В разделе Build and deployment выберите Deploy from a branch, ветку main и папку /(root), затем нажмите Save.
